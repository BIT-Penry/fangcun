# Development

## Prerequisites

- macOS with Xcode Command Line Tools
- Node.js LTS
- pnpm
- stable Rust toolchain

## Run

`pnpm install`

`pnpm tauri dev`

## Validate

`pnpm test:run`

`pnpm typecheck`

`pnpm build`

`cargo check --manifest-path src-tauri/Cargo.toml`

## Rust lockfile follow-up

`src-tauri/Cargo.lock` must be generated by Cargo rather than written by hand. On a macOS development machine, install and select stable Rust, generate the lockfile, verify it, then make CI require it:

```sh
xcode-select --install
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh -s -- -y --default-toolchain stable
source "$HOME/.cargo/env"
rustup toolchain install stable
rustup default stable
cargo generate-lockfile --manifest-path src-tauri/Cargo.toml
cargo check --locked --manifest-path src-tauri/Cargo.toml
```

After the locked check passes, change the CI Cargo command to `cargo check --locked --manifest-path src-tauri/Cargo.toml`, then commit the generated lockfile and CI change:

```sh
git add src-tauri/Cargo.lock .github/workflows/ci.yml docs/development.md
git commit -m "chore: lock Rust dependencies"
```

## Package

`pnpm tauri build -- --bundles app`

The unsigned application is written under `src-tauri/target/release/bundle/macos/`.
