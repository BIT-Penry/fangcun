# v0.1.0-beta.1 发布准备记录

本记录针对候选版本，Release 保持草稿，仓库保持私有。

## 已完成的本地检查

- 37 个前端测试文件、143 项测试通过。
- TypeScript 类型检查通过。
- Rust 单元测试 35 项通过，使用 `cargo test --locked`。
- 生产前端与 arm64 应用编译通过。
- 统一 package.json、Cargo.toml、Cargo.lock 和 Tauri 配置为 `0.1.0-beta.1`。
- 按维护者选择添加 MIT 许可证。
- 检查当前待发布文件与本地 Git refs 可达历史中的常见 API Token、私钥和含凭据 URL 模式；命中仅为 example.com 的单元测试样例。未扫描 GitHub 服务端不可达对象，不等同于完整安全审计。
- 当前待发布文本文件未命中检查的个人绝对路径和常见个人邮箱模式。

本地使用现有依赖运行 npm 脚本。pnpm 包装器尝试重新安装现有 node_modules，因非交互环境而中止；没有强制清空依赖目录。干净环境的冻结锁文件安装由 GitHub CI 另行验证。

## 发布前仍需完成

- Apple Developer ID 签名与公证，或明确限定为接受未公证安装限制的测试群体。本机未发现可用签名身份。
- 在其他 Mac / 隔离用户环境验证首次安装、打开书签、备份恢复与已有数据升级。本次不覆盖用户正在使用的数据。
- 使用有效账户验证 AI 接口与模型权限；自动化测试不代表第三方 API 实测通过。
- 检查 `notice-review.json` 中未随依赖包提供许可证文件的组件，补齐需要的第三方声明；自动收集的 notices 不能当作许可完整性的证明。
- 检查 GitHub CI 结果，再合并现有 PR 到 main。
- 检查最终 Release 安装包、校验和与源码提交对应后，由维护者决定公开仓库和发布草稿。

## 已知构建警告

- 前端主 JS chunk 超过 500 kB，是后续加载性能优化项，不影响本次构建完成。

构建电脑为 Apple 芯片，macOS 26.6.2；这不是已验证的最低支持版本。
