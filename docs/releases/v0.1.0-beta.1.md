# 方寸 v0.1.0-beta.1 · 首个测试版

方寸之间，自有天地。把书签、提示词、Agent Skill、日记与常用工具，收进一个本地工作台。

本版本用于早期体验与问题反馈，尚未完成其他电脑上的完整兼容性验证。

## 支持范围与安装

- 本次提供 Apple 芯片 Mac（arm64 / aarch64）构建；不适用于 Intel Mac 或 Windows。
- 下载 DMG 后，将「方寸」拖入「应用程序」，再从应用程序目录启动。
- 若使用 ZIP 备用包，解压后将「方寸.app」拖入「应用程序」。
- **本包没有 Apple Developer ID 签名，也没有完成苹果公证。** macOS 可能阻止首次打开。仅在确认来源和校验值后，按系统「隐私与安全性」中的提示操作；如果系统仍拒绝，请反馈具体提示。不要全局关闭 Gatekeeper。
- 升级前请在旧版设置中创建备份。当前版本继续使用原应用标识，可能读取已有本地资料。

## 可以体验的功能

- 书签 HTML 导入导出、文件夹层级管理、右键新建与重命名、逐级选择文件夹、搜索和标签。
- 修复文件夹视图点击书签时被拖拽捕获的问题，并改进 macOS 系统浏览器打开路径。
- 提示词的 Markdown 编辑、预览、收藏、复制和 AI 格式校正。
- Skill 文件、ZIP 与 GitHub 链接导入，合集管理，AI 简介与标签，以及可识别的本地依赖打包。
- 日历、每日待办、优先级、心情与 Markdown 随笔。
- 工具箱：公式图片转 LaTeX、Cloudflare 网络测速。
- 明暗主题、全局搜索与数据库备份恢复。

## AI 与数据

基础资料管理无需配置 AI。使用智能整理时，需要在设置中填写自己的服务商、模型和 API Key，相关内容会发送给该服务商，费用由服务商计算。

当前公式识别固定使用 Kimi 的 `kimi-k2.6` 模型，需要可访问该模型的 Kimi 账户；不会跟随设置中的文本模型切换。接口和模型可用性仍需实际账户验证。

核心资料保存在本机 SQLite。API Key 在 macOS 钥匙串中保存，不包含在数据库备份内。测速会连接 Cloudflare 并消耗网络流量；网页获取和 GitHub 导入也需要联网。

## 已知限制

- 未公证安装包的首次启动体验可能因系统版本或管理策略不同而变化。
- 网站可能拒绝自动读取（例如 403）；可以手动填写并保存书签。
- AI 内容和公式识别结果需要核对，实际延迟取决于网络与服务商。
- Skill 依赖识别仅覆盖正文中的特定相对目录引用，不能保证发现所有外部依赖。
- 测速提供到 Cloudflare 端点的参考值，不等同于运营商带宽认证；负载延迟采样尚需更多网络环境验证。
- 没有自动更新和云同步；请保存好本地备份。
